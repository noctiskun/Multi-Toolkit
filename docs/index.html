what's inside

Eight tools, two benches.

Everything below runs locally once you clone the repo. The QR generator above is the one piece that needs no server, which is why it can live on this page at all.

Documentspdf
Merge
Combine any number of PDFs. Drag rows to reorder; optionally add a bookmark for each source file.
Split
A visual page grid. Click between pages to place cut points, or click pages to pull them out. Also every-page, every-N, ranges, and drag-to-reorder with deletion.
Compress
Four presets, each showing a measured result size before you commit — not an estimate. Uses Ghostscript when it's installed, pure Python otherwise.
Convert
Office → PDF, PDF → Word, PDF → PowerPoint, PDF → images, images → PDF.
Mediaa/v
YouTube
Pick a resolution and container, watch live progress. Optionally re-encodes to H.264/HEVC with hardware acceleration so 4K actually plays in QuickTime.
Reels
Instagram, TikTok and Shorts, plus 9:16 reframing — a blurred backdrop that crops nothing, a crop-to-fill, or black bars.
Image
Load from a URL or a file, drag a crop box with locked ratios, rotate, flip, resize, export PNG, JPG or WebP.
QR Codelive above
Links, Wi-Fi, contact cards and more, with a centre logo and a silhouette mode that makes the mark read as part of the code.
the logo trick

Why the mark sits inside the code.

Four things do the work, and the generator applies them for you the moment you add a logo.

Silhouette
Flattens your image to a single colour matching the code, so it reads as part of the pattern rather than a sticker sitting on top.
No plate
Skip the white rectangle behind the mark. The modules simply stop where the shape begins.
Correction H
Recovers roughly 30% of a damaged code. That headroom is what pays for covering the middle, and it switches on automatically.
Square finders
The three big corner squares are never rounded, even in Dots mode. Scanners lock onto them first, and rounding them is the quickest way to break an otherwise valid code.
Scan it before you print it. Every stylistic choice spends error-correction headroom. The generator warns you when the logo grows too large, the quiet zone drops below four modules, or contrast falls too low — but a real phone camera is the only test that counts.
running it

One file. One command.

Python 3.8 or newer is the only hard requirement. Packages install themselves the first time a feature needs them.

git clone https://github.com/<your-username>/multi-toolkit.git
cd multi-toolkit
python multi_toolkit.py

Your browser opens at http://127.0.0.1:8000. Press Ctrl+C in the terminal to stop. If the port is busy it moves to the next free one and prints where it landed.

why local

Nothing leaves the room.

No upload
The server binds to 127.0.0.1 and nothing else. It isn't reachable from your network.
No limits
No free tier, watermark, daily cap or sign-up. The constraint is your own disk and CPU.
No black box
One readable file. No build step, no framework, no node_modules.
