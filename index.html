Multi Toolkit

PDFs, video and QR codes in one browser tab — served by a tiny Python file running on your own machine. Your files never leave your computer, because there is no server to send them to.

What it does

Two groups of tools, eight tabs. The browser is just the interface — there's no GUI framework to install and nothing to sign into.

PDF

Merge

Combine any number of PDFs, drag the rows to reorder, and optionally drop a bookmark in for each source file.

Split

A visual page grid: click between pages to place cut points, or click pages to pull them out. Also every-page, every-N, ranges and full reordering.

Compress

Four presets with real size estimates measured before you commit — from lossless structure cleanup to hard image downscaling.

Convert

Office → PDF, PDF → Word, PDF → PowerPoint, PDF → images, and images → PDF.

Photo & Video

YouTube

Pick a resolution and container, watch live progress, and optionally re-encode to HEVC/H.264 so 4K actually plays in QuickTime.

Reels

Instagram, TikTok and Shorts — plus 9:16 reframing with a blurred backdrop that crops nothing, a crop-to-fill, or plain black bars.

Image

Load from a URL or a file, drag a crop box with locked ratios, rotate, flip, resize, and export PNG, JPG or WebP.

QR CodeLIVE BELOW

Links, Wi-Fi, contact cards and more, with a centre logo and a silhouette mode that makes the logo read as part of the code.

Running it

One file, one command. Dependencies install themselves the first time a feature needs them.

git clone https://github.com/<your-username>/multi-toolkit.git
cd multi-toolkit
python multi_toolkit.py

Your browser opens automatically at http://127.0.0.1:8000. Press Ctrl+C in the terminal to stop it.

This page can't run the whole app. GitHub Pages serves static files only — there's no Python process behind it, so merge, split, video download and image cropping genuinely cannot work here. The QR generator above is the exception, because QR encoding needs no server. Everything else requires the clone-and-run above.

Why local

Nothing is uploaded

The server binds to 127.0.0.1 and nothing else. Your documents are never transmitted, because there is nowhere to transmit them to.

No page limits

No free tiers, watermarks, daily caps or sign-ups. The constraint is your own disk and CPU.

It's one file

Read it, audit it, change it. No build step, no framework, no node_modules.
